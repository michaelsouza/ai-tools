# Default to the user's cloned voice

`md2audio.py` with no options now narrates in pt-BR with the local Qwen3-TTS engine, cloning the user's recorded voice `michael` (ADR 0003), and slows the result to 0.86×; this replaces Gemini as the default engine from ADR 0002 and makes `--language` optional. The user chose these defaults after hearing John 1–5 in their own voice: it read the whole text without the skips the preset speaker made, costs nothing per run and keeps the text on the machine, which outweighed Gemini's higher listening score (4.95/5). The tempo default belongs to the clone, not to the tool: the clone speaks about 2.9 words/s against 2.45 in its reference recording, so 0.86 restores the recorded pace, while preset speakers and Gemini keep 1.0. Choosing another voice is one flag that also drops the clone's tempo: `--speaker` or `--instruct` switch to the Qwen preset speakers and `--engine gemini` to Gemini; an explicit `--voice` combined with any of them is rejected as contradictory, and an explicit `--tempo` always wins. On a machine without `models/voices/michael.wav` the default fails with instructions to record a voice or pick `--speaker`/`--engine gemini`, rather than silently changing voice.
