# Clone the user's voice with Qwen3-TTS 1.7B Base

`md2audio.py --voice <name>` narrates in a recorded voice by zero-shot cloning with `Qwen/Qwen3-TTS-12Hz-1.7B-Base` (in-context mode: the reference audio plus its exact transcript), which ADR 0002 had left out until someone needed a custom voice. The user asked for narrations in their own voice, and among the local models Qwen3 Base was the one already evaluated for cloning: 1.4% core WER in the pt-BR benchmark at 5.5 GB of VRAM, with an Apache-2.0 license, while Fish S2 Pro needs 7.6 GB and a non-commercial license. The reference is a single 10–20 s take of one of three fixed reading texts in `docs/voice_reference.md`; `tools/voice_ref.py` picks the cleanest take, checks it against its text with Whisper, and stores it with the exact transcript in `models/voices/`, which is git-ignored so the recording never leaves the machine. A fixed text keeps the transcript exact, which in-context cloning depends on, and two takes per text guard against noise and stumbles. `--voice` implies the local engine and excludes `--speaker` and `--instruct` (the Base model has neither); Gemini stays the default for narration without a personal voice.
